# Issue #313: TGEVC from an existing generalized Schur pencil

Status: the 4 Fortran S/D/C/Z entries and 8 LAPACKE high/work entries are
connected and pass focused numerical, diagnostic, layout and independent C ABI
checks. Issue #313 is complete after the full-suite evidence below is recorded.

## What was connected

- `{s,d,c,z}tgevc_` for LP64 and ILP64.
- `LAPACKE_{s,d,c,z}tgevc` and `LAPACKE_{s,d,c,z}tgevc_work` for both integer
  ABIs and both layouts.

The Fortran owner consumes the caller's `S`/`P` pencil. It does not repeat a QZ
factorization and does not delegate to a normal generalized-EVD driver. The
back-substitution and protected small solves are a local adaptation of
colmat-rs revision `4e6ed0e34659147a5c744ab6431f150e78db6f82`
`linalg/gevd/mod.rs` private helpers, with attribution in
`deps/rust/src/tgevc.rs`.

## Contracts

- SIDE `L`/`R`/`B`; HOWMNY `A`/`S`/`B`.
- Real 2x2 blocks produce adjacent real/imaginary columns; SELECT of either
  member selects the pair.
- HOWMNY `S` packs selected vectors into the leading columns and leaves the
  remaining columns unreferenced; `M` is the selected count.
- HOWMNY `B` consumes `Q`/`Z` from `VL`/`VR`, returns `Q*Y`/`Z*X`, and
  preserves the caller's leading dimensions.
- `alpha/beta` is never formed by the routine; infinite eigenvalues are handled
  by the zero `P` pivot path.
- Each requested vector is normalized to maximum component magnitude one;
  real pairs use the pair maximum.
- Invalid SIDE/HOWMNY, overlapping real blocks, non-triangular `P` blocks,
  leading dimensions, insufficient `MM`, and empty `N` follow the reference
  `INFO` contract. `M` is unchanged on error.
- The LAPACKE work entry checks row-major leading dimensions and converts only
  the logical `S`, `P`, `VL`, `VR` rectangles. High-level entries check NaNs in
  `P` (-8), `S` (-6), `VL` (-10) and `VR` (-12) in the reference order, then
  allocate real `6n` / complex `2n` work. Negative Fortran `INFO` shifts by one
  for the layout argument.

## Tests

- Four scalar types, both integer ABIs, both layouts, high/work, DLL and LBT
  routes.
- Random pencils generated by independent QZ (`LAPACK.gges!`) and checked
  against `A`, `B` residuals and `S`, `P` residuals for every SIDE/HOWMNY.
- Real conjugate pairs, explicit 2x2 blocks, infinite eigenvalues, selection
  counting/packing, max-component normalization and untouched sentinels.
- Invalid flags, overlapping blocks, zero `P` diagonal, leading dimensions,
  `MM`, empty `N`, NaN order and layout conversion.
- Independent C11 `-Wall -Wextra -Werror` caller for all 16 symbol/ABI
  variants.

## Remaining limits

The implementation adapts colmat-rs's private helpers; no native API change is
claimed. LAPACK's exact bit patterns and all extreme scaling paths are not
claimed, only the documented eigenvalue/vector residual, normalization and
diagnostic contracts exercised above.
