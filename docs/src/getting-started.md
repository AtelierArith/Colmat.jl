# 計算の選び方と用語

Juliaの配列操作は分かるけれど、分解や求解という言葉には慣れていない読者向けの案内です。

## 連立方程式を解く

`A * x = b`を満たす未知のベクトル xを求めることを「求解」と呼びます。Aは係数行列、bは右辺です。Juliaでは `x = A \ b`と書きます。

```julia
using Colmat, LinearAlgebra
A = FaerMatrix([4.0 1; 1 3])
b = [1.0, 2.0]
x = A \ b
@assert Matrix(A) * x ≈ b
```

`≈`は丸め誤差を考慮した比較です。`b - A*x`は「残差」で、計算した解が式をどれだけ満たすかを表します。小さい残差でも、条件の悪い行列では解そのものの誤差が大きい場合があります。

解だけが目的なら `inv(A) * b` より `A \ b`を使ってください。逆行列全体を作る必要がありません。

## 右辺を変えて繰り返し解く

「分解」は行列を計算しやすい部品（因子）へ分ける前処理です。同じ Aを何度も使うなら、分解を保存するとその作業を繰り返さずに済みます。

```julia
using Colmat, LinearAlgebra
A = FaerMatrix([4.0 1; 1 3])
F = lu(A)
x1 = F \ [1.0, 2.0]
x2 = F \ [3.0, 4.0]
@assert Matrix(A) * x2 ≈ [3.0, 4.0]
```

| 問題 | 最初に使う関数 | 補足 |
| :--- | :--- | :--- |
| 正方行列の連立方程式 | `A \ b`、保存するなら `lu(A)` | 特異な場合は通常の解が一意に定まらない |
| 観測数が未知数より多い | `qr(A) \ b` | 残差の二乗和を最小にする最小二乗問題 |
| 自己随伴かつ正定値と分かっている | `cholesky(Hermitian(A))` | 正定値の条件が必要 |
| 列が独立でない・数値ランクを調べたい | `svd(A)`、`rank(A)`、`pinv(A)` | 小さな特異値の扱いを許容誤差で決める |
| 大きな疎行列 | 疎 LU・疎 QR、または反復法 | 分解中に非ゼロが増える場合もある |

## 最小二乗と最小ノルム

観測に誤差があると、すべての式を同時に満たす xは存在しないことがあります。その場合に `norm(A*x - b)`を最小にするのが最小二乗です。

```julia
using Colmat, LinearAlgebra
# 3 点の観測を、切片と傾きの 2 個の未知数で近似する
A = FaerMatrix([1.0 0; 1 1; 1 2])
b = [1.0, 2.0, 2.0]
x = qr(A) \ b
@assert norm(Matrix(A)' * (Matrix(A) * x - b)) < 1e-12
```

未知数の方が多いなど、最小二乗解が複数ある場合は、その中で `norm(x)`が最小のものを最小ノルム解と呼びます。`pinv(A) * b`はその解を表す方法です。大きな問題では疑似逆行列全体を作らず、保存因子の求解機能を使う方が省メモリです。

## 読み進めるための用語

| 用語・記法 | 意味 |
| :--- | :--- |
| 密行列 / 疎行列 | 全要素を格納する行列 / 主に非ゼロの位置と値を格納する行列 |
| `transpose(A)` / `A'` | 転置 / 転置して複素共役を取る随伴。実数なら同じ |
| 自己随伴 / Hermitian | `A == A'`。実数では対称行列 |
| 正定値 | 非ゼロの xに対して `real(x' * A * x) > 0` |
| ランク | 独立な列の数。数値計算では小さな値を許容誤差でゼロとみなす |
| ノルム | ベクトルや行列の大きさを測る数値 |
| 条件数 | 入力誤差に対する解の敏感さの目安。大きいほど敏感 |
| 固有値・固有ベクトル | `A*v = λ*v`を満たす倍率 λと非ゼロの方向 v |
| 特異値 | SVDで得られる非負の拡大率。長方形の行列にも定義できる |
| 所有 / 借用 | メモリを自分で保持すること / 元の配列を参照して使うこと |
