Colmat.jl ​

Colmat は Rust の colmat を使う Julia の BLAS バックエンドです。 using Colmat で libblastrampoline (LBT) に転送先を登録し、通常の Julia 配列と LinearAlgebra の API から計算します。

julia
julia> using Colmat, LinearAlgebra

julia> A = [4.0 1; 1 3]; B = [2.0 0; 0 2];

julia> A * B == [8.0 2; 2 6]
true

julia> C = similar(A); mul!(C, A, B); C == A * B
true

読み進め方 ​

  • インストール: 必要な環境と初回ビルド。

  • はじめに: 行列積、ベクトル演算、転送先の確認。

  • バックエンドとフォールバック: プロセス全体の切り替えと LAPACK の扱い。

  • スレッド設定: Colmat と既存バックエンドの並列実行幅。

  • BLAS 対応範囲: 型・整数 ABI・提供ルーチン。

  • トラブルシューティング: ビルドやロードで困ったときの確認。

対象とする計算 ​

Float32 / Float64 / ComplexF32 / ComplexF64、LP64 / ILP64 に対応します。 GEMM・GEMV と行列積を利用する Level 3 演算では Rust colmat のカーネルを使い、 ベクトル演算と三角求解の一部はこのパッケージの Rust 互換層で実行します。

未提供の BLAS と LAPACK は既存バックエンドを使います。lu・svd・eigen そのものを Rust colmat の分解に置き換える機能はありません。

0.2 への設計変更で専用行列型による旧 API を廃止しました。
